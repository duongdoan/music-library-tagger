# Cài đặt

## APP-SET — Cài đặt ứng dụng

### Màn hình / giao diện
Cửa sổ Cài đặt (Cmd+,) với các nhóm:
- **Thư viện**: danh sách nguồn (tên, đường dẫn, thư mục đích mặc định), "Quét lại khi mở app", "Định dạng hỗ trợ".
- **Ghi tag**: "Giữ nguyên ngày sửa file".
- **Lịch sử**: "Thời gian giữ lịch sử", "Số mục tối đa".
- **Dọn file**: "Dọn cả .cue".
- **Giao diện**: Sáng / Tối / Theo hệ thống.

### Quy tắc nghiệp vụ áp dụng
APP-TAG-R1, APP-SCAN (cấu hình), APP-WRITE-R9, APP-UNDO-R6, APP-FILEOP-R10.
